To change or add a sound: edit `Tools/generate_sounds.py`, run `python3 Tools/generate_sounds.py` (or name only the
sounds to rebuild, e.g. `python3 Tools/generate_sounds.py riseup_birds`), rebuild the app. The newer sounds use
real instrument techniques: bell overtones, plucked strings (Karplus–Strong), FM electric piano, brass and drums,
and loop seamlessly (iOS repeats the 12-second file). The "Around the world" sounds (2026-10-13) add
harmonic tones (sitar drone, accordion reeds, bagpipes, alpine horn), breathy flutes, membranes (drums),
steel-pan and singing-bowl partials, and filtered noise (rain, surf, thunder). Each one is also the signature
sound of a wallpaper (`LiveWallpaper.signatureSound`).

**Important:** the file names are stored in the database (`WakeAlarm.soundName`). Never rename a shipped file.
Add a new one instead (see `AlarmSound.swift`).

## Icons
| Asset | Source | Licence |
|---|---|---|
| All in-app icons | SF Symbols | Free to use in apps on Apple platforms (not as the app icon) |
| App icon (normal, dark, tinted) + in-app logo `AppLogo` | Drawn by `Tools/generate_app_icon.swift` (CoreGraphics) | Our own work: no restrictions |

**The logo (v3, "the Crowing Rooster", 2026-10-14):** a rooster, nature's alarm clock, crowing at the sky.
Its head is the sun (gold), its comb the sun's rays (three pink lobes), its open beak and two sound waves are the
crow (the alarm). The bird leans back 10° ("Rise Up") on a night sky with dawn glowing up from the bottom edge.
Six simple shapes, so it reads at every size. No alarm app uses a rooster (they use twin-bell clocks, digits or
cartoon clock faces). To change it: edit the numbers at the top of the script, run
`swift Tools/generate_app_icon.swift`, rebuild. It writes all 3 icon versions and the in-app logo at once.

Format: 40-second seamless loops (1.5 s crossfade at the seam), 22.05 kHz mono, IMA4 CAF (~470 KB each, ~4.5 MB total).

**Important:** the file name is the `SleepSound` raw value and is saved in "last mix". Never rename a shipped file.
