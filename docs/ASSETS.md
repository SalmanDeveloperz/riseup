# RiseUp Assets & Licences

Every sound, image and font that ships in the app, where it came from, and whether we may use it.
**Rule:** nothing goes into the app without a row here. The App Store review (and the law) care about licences.

## Alarm sounds (`Alarm/Resources/Sounds/`)
| File | Name in app | Source | Licence |
|---|---|---|---|
| `riseup_digital.caf` | Digital | Generated by `Tools/generate_sounds.py` | Our own work: no restrictions |
| `riseup_radar.caf` | Radar (default for new alarms) | Generated | Our own work |
| `riseup_bell.caf` | Bell | Generated | Our own work |
| `riseup_siren.caf` | Siren | Generated | Our own work |
| `riseup_pulse.caf` | Rapid Pulse | Generated | Our own work |
| `riseup_arcade.caf` | Arcade | Generated | Our own work |
| `riseup_sunrise.caf` | Sunrise | Generated | Our own work |
| `riseup_marimba.caf` | Marimba | Generated | Our own work |
| — | iPhone Alarm | iOS system sound (`AlertSound.default`) | Provided by iOS; not bundled |

Format: 12 seconds, IMA4-compressed CAF (~280 KB each), which both AlarmKit and `AVAudioPlayer` can play.
To change or add a sound: edit `Tools/generate_sounds.py`, run `python3 Tools/generate_sounds.py`, rebuild.

**Important:** the file names are stored in the database (`WakeAlarm.soundName`). Never rename a shipped file.
Add a new one instead (see `AlarmSound.swift`).

## Sleep sounds (`Alarm/Resources/SleepSounds/`)
| File | Name in app | Source | Licence |
|---|---|---|---|
| `sleep_rain.caf` | Rain | Generated by `Tools/generate_sleep_sounds.py` | Our own work: no restrictions |
| `sleep_ocean.caf` | Ocean | Generated | Our own work |
| `sleep_stream.caf` | Stream | Generated | Our own work |
| `sleep_wind.caf` | Wind | Generated | Our own work |
| `sleep_crickets.caf` | Night | Generated | Our own work |
| `sleep_fire.caf` | Fireplace | Generated | Our own work |
| `sleep_fan.caf` | Fan | Generated | Our own work |
| `sleep_white.caf` | White noise | Generated | Our own work |
| `sleep_pink.caf` | Pink noise | Generated | Our own work |
| `sleep_brown.caf` | Brown noise | Generated | Our own work |

Format: 40-second seamless loops (1.5 s crossfade at the seam), 22.05 kHz mono, IMA4 CAF (~470 KB each, ~4.5 MB total).
All are normalised to the same loudness (RMS 0.15), so a mix doesn't need fiddling.
To change one: edit `Tools/generate_sleep_sounds.py`, run `python3 Tools/generate_sleep_sounds.py`, rebuild.

**Important:** the file name is the `SleepSound` raw value and is saved in "last mix". Never rename a shipped file.
