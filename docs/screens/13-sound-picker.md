# Screen #13 · Sound Picker: brief & review guide

**Phase 1** · on `development`

## What it does
A sheet listing RiseUp's alarm sounds in three sections, **Classic**, **Loud** and **Gentle**:
- Tap a row to select it **and** hear a short preview. The row shows an animated speaker while it plays.
- **Done** sends the choice back to the Alarm Editor. **Cancel** (or swiping down) changes nothing.
- 8 original sounds + "iPhone Alarm" (the system sound). The sounds are generated by `Tools/generate_sounds.py`,
  so there are no licence issues (see `docs/ASSETS.md`).

## Connection map
```
AlarmEditorView "Sound" card
  → AlarmEditorViewModel.chooseSound()
  → AppCoordinator.presentSoundPicker(selected:onPick:)   ← stores the callback
  → sheet = .soundPicker → RootView .sheet → ScreenFactory
       └─ SoundPickerView ── owns ──► SoundPickerViewModel
                                        ├─► AudioPlaying.preview / stopPreview  (AudioService → AVAudioPlayer)
                                        └─► AppCoordinator.completeSoundPicker(with:)
                                              → runs the stored callback → editor's draft.sound = choice
                                              → sheet = nil
```

## Files, in reading order
1. `Models/AlarmSound.swift`: the enum; raw values are file names (never rename them!)
2. `Services/Audio/AudioService.swift`: `AudioPlaying` protocol, real player, mock
3. `Coordinator/AppCoordinator.swift`: `presentSoundPicker` / `completeSoundPicker` (the callback pattern)
4. `Features/SoundPicker/ViewModels/SoundPickerViewModel.swift`
5. `Features/SoundPicker/Views/SoundPickerView.swift`
6. `Tools/generate_sounds.py`: how the `.caf` files were made (optional, Python)

## Data
| Reads | Writes |
|---|---|
| The current draft sound (passed in) | Nothing. The editor's draft changes; the database only changes when you tap the editor's **Save**. |

## Design decisions (WHY)
- **Sheet results come back through a stored closure** in the coordinator (`onSoundPicked`). The picker doesn't
  know who opened it, so it can be reused anywhere (e.g. onboarding in Phase 4).
- **`@ObservationIgnored` on the callback:** a closure isn't UI state. Without it, SwiftUI would track it for no reason.
- **`.caf` files in `Resources/Sounds`:** AlarmKit can only play sounds from the app bundle (or `Library/Sounds`).
  The same files are used by AlarmKit (app closed) and by `AudioService` (app open).
- **Known iOS bug:** on some iOS 26.x versions `AlertSound.named` plays the default sound. Check on your iPhone.

## How to try it
1. **+** → Sound card → tap **Siren** (you hear it) → **Done** → the card says Siren.
2. Open again → tap **Bell** → **Cancel** → still Siren.
